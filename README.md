# EvenOddDigitCounter

## 🇬🇧 About

EvenOddDigitCounter is a practical JavaScript exercise designed to improve programming skills and practice working with numbers and strings.

## Description

In this application, the user enters a number, and the program checks its digits and separates them into even and odd groups.

It also calculates and displays the total number of even and odd digits across all submitted numbers.

## Features

- Accepting numeric input from the user
- Input validation using Regular Expressions
- Separating even and odd digits
- Displaying even and odd digits of the latest input
- Counting all even and odd digits across multiple inputs
- Preventing invalid input from being submitted

## Built With

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Learning Objectives

This project is mainly a JavaScript practice exercise covering:

- Variables
- Functions
- Conditions (if / else)
- Loops
- Arrays
- String Iteration
- Regular Expressions (Regex)
- DOM Manipulation
- Array Methods
